Project: Sistem Manajemen CafeKita

Halo! Ini adalah repo buat nyimpen tugas website Sistem Manajemen CafeKita. Intinya sih website ini dibuat buat mantau bisnis cafe harian, dari mulai berapa menu yang laku sampe total cuan yang masuk.

Bagian <head> (kepala atau atasanyaa)
Di bagian paling atas (head to head), isinya bukan tampilan, tapi "perintah" buat browser.

Bootstrap 5 & Icons: Kita nggak usah ribet ngoding CSS dari nol. Kita "pinjem" CSS-nya Bootstrap biar tombol sama kartunya langsung rapi. Plus, ada ikon-ikon keren kayak gambar keranjang sama tumpukan duit.

Viewport: Ini penting banget biar pas dibuka di HP, tampilannya nggak berantakan (responsive).

Bagian <body> (Badannya)
Nah, ini yang bakal muncul di layar user. Isinya gue bagi-bagi jadi beberapa blok:

- Navbar (Menu Atas)
Gue pake warna item (bg-dark) biar keliatan clean dan elegan. Isinya simpel cuma nama brand kita: CafeKita.

- Hero (Sapaan Awal)
Cuma buat pemanis di awal aja. Ada judul gede dan deskripsi singkat kalau ini adalah web buat manajemen cafe. Dibikin rata tengah biar fokusnya dapet.

- Statistik Harian
Ini bagian favorit gue! Pake sistem kotak-kotak (card) biar informasinya enak dibaca.

1 Total Menu: Buat nunjukin koleksi makanan/minuman kita.

2 Porsi Terjual: Biar tahu hari ini lagi rame apa nggak.

3 Pendapatan: Bagian paling penting, total duit yang masuk dalam bentuk Rupiah.

-  Menu Andalan
Di sini gue tampilin dua menu jagoan: Beef Meals sama Coffee Latte.

Gambarnya gue taro di folder assets/.

Gue pake sedikit trik d-flex sama w-100 biar tinggi kartu menu makanan sama minumannya sama rata. Jadi nggak bakal jomplang kalau gambar satunya lebih pendek.

- Footer (Kaki)
Cuma penutup di paling bawah. Isinya teks copyright standar biar keliatan makin official.
